# Toontown Browser maintenance

- Do not create backup copies or snapshots before routine code changes or
  deployments. The owner requested this to avoid unnecessary time and copying.
- Preserve existing backups and the protected classic/OG snapshot. Do not modify
  the separate scheduled daily player-state backup system as part of code work.
- Cog Mega-Buildings are retired. Regular street Cog Buildings have one-to-five
  floors and at most four Toons. Keep the reserved distributed-schema fields
  inert so removing the feature does not renumber the live protocol.
